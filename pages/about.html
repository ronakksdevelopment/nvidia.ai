About Nemotron

What this project is, and how it works.

What this is

NVIDIA Nemotron is a chat interface built to explore NVIDIA's open Nemotron model family. Bring your own free OpenRouter API key and talk directly to NVIDIA's free Nemotron models available on OpenRouter. There is no backend server and no account system beyond a local, on-device identity: your name, email, settings, and chat history live only in this browser.

How it works

Your OpenRouter API key is saved only in this browser's localStorage. When you send a chat message or run the connection test in Settings, your browser calls OpenRouter's API directly using that key. Nothing passes through a Nemotron-owned server.

Project status

Nemotron v2.5 covers real-time streaming chat with NVIDIA's free Nemotron models, API key management, model selection, dark/light/system theming, a live connection test, and a local account and guest-mode system. Conversation history is saved on-device for signed-in sessions and never saved for guest sessions.

Models

Nemotron organizes the free NVIDIA models available through OpenRouter into three categories. Pick a text model for chat, an embedding model for retrieval, or the rerank model for reordering search results.
