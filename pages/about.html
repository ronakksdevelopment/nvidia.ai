About Nemotron

What this project is, and what it isn't — yet.

What this is

NVIDIA Nemotron v1.0 Beta is a frontend-only chat interface built to explore NVIDIA's open Nemotron model family. This build lets you bring your own OpenRouter API key and talk directly to any of the eight free NVIDIA Nemotron models currently available on OpenRouter — no backend, no account system, and no server-side storage.

How it works

Your OpenRouter API key is saved only in this browser's localStorage. When you send a test message or a chat, this page calls OpenRouter's API directly from your browser using that key. Nothing passes through a Nemotron-owned server in this build.

Project status

This is an early beta focused on the Settings & OpenRouter milestone: API key management, model selection, theme preferences, and a live connection test. Routing between pages, a web app manifest, deployment tooling, and final visual polish are tracked as later milestones and are intentionally out of scope for this build.

Model family

Eight free NVIDIA Nemotron models are wired into the model picker in Settings:

  • nvidia/nemotron-3-ultra-550b-a55b:free — frontier reasoning & orchestration
  • nvidia/nemotron-3.5-lightning:free — high-throughput agentic workloads
  • nvidia/nemotron-3-super-120b-a12b:free — balanced multi-agent reasoning
  • nvidia/nemotron-3-nano-omni-30b-a3b-reasoning:free — compact omni-modal reasoning
  • nvidia/llama-nemotron-rerank-vl-1b-v2:free — multimodal reranking
  • nvidia/nemotron-3.5-content-safety:free — content moderation & guardrails
  • nvidia/llama-nemotron-embed-vl-1b-v2:free — multimodal embeddings
  • nvidia/nemotron-3-embed-1b:free — text embeddings

Built with

Vanilla HTML, CSS, and JavaScript — no frameworks, no build step, no dependencies beyond Google Fonts.
