About Nemotron

What this project is, and how it works.

What this is

NVIDIA Nemotron is a chat interface built to explore NVIDIA's open Nemotron model family. Bring your own free OpenRouter API key and talk directly to any of the eight free NVIDIA Nemotron models available on OpenRouter. There is no backend server and no account system beyond a local, on-device identity: your name, email, settings, and chat history live only in this browser.

How it works

Your OpenRouter API key is saved only in this browser's localStorage. When you send a chat message or run the connection test in Settings, your browser calls OpenRouter's API directly using that key. Nothing passes through a Nemotron-owned server.

Project status

Nemotron v1.5 covers real-time streaming chat with all eight free models, API key management, model selection, dark/light/system theming, a live connection test, and a local account and guest-mode system. Conversation history is saved on-device for signed-in sessions and never saved for guest sessions.

Model family

Eight free NVIDIA Nemotron models are wired into the model picker in Settings and in chat:

  • nvidia/nemotron-3-ultra-550b-a55b:free: frontier reasoning and orchestration
  • nvidia/nemotron-3.5-lightning:free: high-throughput agentic workloads
  • nvidia/nemotron-3-super-120b-a12b:free: balanced multi-agent reasoning
  • nvidia/nemotron-3-nano-omni-30b-a3b-reasoning:free: compact omni-modal reasoning
  • nvidia/llama-nemotron-rerank-vl-1b-v2:free: multimodal reranking
  • nvidia/nemotron-3.5-content-safety:free: content moderation and guardrails
  • nvidia/llama-nemotron-embed-vl-1b-v2:free: multimodal embeddings
  • nvidia/nemotron-3-embed-1b:free: text embeddings

Built with

Vanilla HTML, CSS, and JavaScript. No frameworks, no build step, no dependencies beyond Google Fonts.
