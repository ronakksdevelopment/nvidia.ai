Privacy Policy

How this beta build handles your data.

Beta placeholder policy — last updated September 2026.

Summary

This is a frontend-only demo. There is no account system and no application server that stores your data. The only persistent data this site keeps is what you explicitly save in Settings, and it stays in your browser.

What is stored, and where

Your OpenRouter API key, selected model, and theme preference are saved using your browser's localStorage. This data never leaves your device except when it is sent directly to OpenRouter's API as part of a request you initiate (for example, clicking "Send test message" or sending a chat message).

Third-party services

When you use your saved API key, requests are sent directly from your browser to OpenRouter (openrouter.ai), which routes them to the selected NVIDIA Nemotron model. OpenRouter's own privacy policy governs how they and their model providers handle that traffic. We recommend reviewing it at openrouter.ai before sending sensitive information through this interface.

Clearing your data

You can remove everything this site has stored at any time using the Reset settings control in Settings → General & OpenRouter, or by clearing your browser's site data for this page.

Cookies and tracking

This build does not set cookies and does not include analytics or tracking scripts.

Changes to this policy

As this project moves past the beta milestones, this policy will be updated to reflect any backend or account features that are added.
