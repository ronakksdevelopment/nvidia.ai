Quickstart

Install the CLI, authenticate, and deploy your first endpoint in under five minutes.

terminal 
# Install
curl -fsSL https://accelerate.dev/install.sh | sh

# Authenticate
accelerate login

# Deploy
accelerate deploy ./my-model --gpu a100-40gb

CLI reference

The CLI covers deployment, scaling, logs, and secrets management. Common commands:

reference 
accelerate deploy <path|repo>      # create or update an endpoint
accelerate list                    # list active endpoints
accelerate logs <endpoint>         # stream endpoint logs
accelerate scale <endpoint> --min 1 --max 8
accelerate secrets set KEY=value
accelerate delete <endpoint>

API reference

Every endpoint exposes a versioned REST API with optional streaming over Server-Sent Events.

request 
curl https://api.accelerate.dev/v1/endpoints/<name>/infer \
  -H "Authorization: Bearer $ACCELERATE_KEY" \
  -H "Content-Type: application/json" \
  -d '{"prompt": "Hello", "stream": false}'

Autoscaling config

Set a minimum warm pool to avoid cold starts, or leave it at zero to only pay for active traffic. Configuration lives in accelerate.yaml at your project root:

accelerate.yaml 
gpu: a100-80gb
scaling:
  min_replicas: 0
  max_replicas: 12
  target_concurrency: 4

Security

All traffic is encrypted in transit with TLS 1.3. Endpoints are isolated per-workspace, and secrets are encrypted at rest with per-tenant keys. Accelerate is SOC 2 Type II audited annually; the report is available on request from Enterprise plans.
