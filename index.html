Workflow

From artifact to endpoint in three steps

No cluster to provision and no YAML to hand-write before your first request goes through.

Step 1

Connect your model

Point Accelerate at a Hugging Face repo, an S3 bucket, or push a container image directly with the CLI.

Step 2

Set your scaling policy

Choose a GPU class, a concurrency target, and a minimum warm pool — or let autoscaling handle it from defaults.

Step 3

Call your endpoint

Every deployment gets a versioned REST and streaming endpoint, ready for production traffic immediately.

Developer experience

Deploy from a terminal, not a console

The CLI mirrors the API one-to-one, so anything you can click, you can script.

terminal 
# Authenticate once
accelerate login

# Deploy a model from Hugging Face
accelerate deploy meta-llama/Llama-3.1-70B-Instruct \
  --gpu a100-80gb --min-replicas 0 --max-replicas 12

# Endpoint is live — call it immediately
curl https://api.accelerate.dev/v1/endpoints/llama-3-1-70b/infer \
  -H "Authorization: Bearer $ACCELERATE_KEY" \
  -d '{"prompt": "Summarize this deployment"}'
